# Installazione Vortex Hub 2.25.2

1. Conserva una copia di backup dei dati prima di aggiornare.
2. Sostituisci i file della precedente installazione con quelli dell'archivio mantenendo la struttura.
3. Riapri Vortex Hub; per PWA chiudi completamente e riapri per aggiornare la shell.
4. Verifica backup e ripristino su un dispositivo di prova.

Non disinstallare l'app o cancellare dati locali finché non hai verificato il backup.
