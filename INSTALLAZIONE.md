# Installazione Vortex Hub 2.25.3

Caricare/sostituire i file del pacchetto sul hosting. Se l'app installata non aggiorna subito, aprire la pagina web in Chrome, usare la funzione Ripara e ricaricare; la riparazione rimuove cache e Service Worker, non i dati locali dell'app. Prima di operazioni di ripristino, mantenere un backup.
